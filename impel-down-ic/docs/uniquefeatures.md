# Unique Features (Differentiators)

## Must-Wow (build these first)
1. **Golden Den Den Mushi Buster Call Overlay** — full-screen cinematic: golden snail rings, Akainu silhouette, "BUSTER CALL INITIATED", screen shake, siren sound, auto-dismiss + persistent red banner.
2. **Impel Down Tower Map** — vertical tower (Level 1 → 6) showing live incident counts per level, glowing hotter toward Eternal Hell; click a level to filter.
3. **Escalation Ladder Visual** — each incident shows Jailer → Hannyabal → Magellan → Akainu with the current rung lit and a progress bar to the next escalation.
4. **Poison Gas Meter** — Magellan's Venom Demon gauge: overall "Prison Danger" rises with overdue/critical incidents.
5. **Demo Mode (time warp)** — 1x/10x/60x speed toggle so judges watch escalations in seconds; "Trigger Riot" button spawns random incidents.

## Theme Polish
6. **Wanted-Poster Incident Cards** — parchment style, "BOUNTY" replaced by severity points.
7. **Den Den Mushi Live Feed** — ticker of events written in-character ("Hannyabal has taken command of Cell Riot #12!").
8. **Seastone Dark UI** — Marine-blue/Seastone palette, level-specific backgrounds (Crimson, Burning, Freezing).
9. **Team Bounty Leaderboard** — teams earn points for fast resolutions; lose points on escalation.
10. **Devil Fruit Tags** — optional tags (e.g. "Seastone-Resistant", "Logia Threat") shown as chips.

## Ops Value
11. **SLA Analytics** — compliance %, mean time to resolve, escalation rate per category.
12. **Incident Timeline** — chronological events with icons and actor.
13. **Keyboard Shortcuts** — `N` new incident, `1/2/3` switch views, `R` resolve selected.
14. **Sound Toggle & Reduced Motion mode** for accessibility.
15. **Export** — download incident history as CSV.

## Prioritization
Do 1, 3, 5 first (biggest judge impact per hour), then 2 and 4, then the rest as time allows.
